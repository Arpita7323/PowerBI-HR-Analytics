 HR Analytics Dashboard | Power BI

## Overview

Developed an interactive HR Analytics Dashboard using Power BI to create meaningful visualizations, track key HR metrics, and generate actionable business insights through data analysis.

## Tools & Technologies Used

* Power BI Desktop
* Power Query
* DAX (Data Analysis Expressions)
* Data Modeling
* Microsoft Excel

## Power BI Features Implemented

* KPI Cards
* Donut Charts
* Bar Charts
* Column Charts
* Matrix Visuals
* Interactive Filters & Slicers
* Custom Visual Formatting
* Data Relationships
* Calculated Measures

## DAX Functions Used

* SUM()
* COUNT()
* DISTINCTCOUNT()
* DIVIDE()
* AVERAGE()
* IF()
* CALCULATE()
